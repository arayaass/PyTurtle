PENGEMBANGAN LINGKUNGAN PEMBELAJARAN INTERAKTIF 
BERBASIS WEB UNTUK PEMROGRAMAN TURTLE DENGAN MODEL 
TUTORIAL (Oleh: Khoyrur Roykhan; Pembimbing: Harja Santana Purba, Rizky 
Pamuji; 2025; 98 halaman) 
 
ABSTRAK 
 
Pada mata pelajaran Informatika kelas VII Kurikulum Merdeka, algoritma dan 
pemrograman diperkenalkan menggunakan Scratch. Namun, untuk membantu 
siswa beralih ke pemrograman tekstual, dibutuhkan pendekatan yang ramah 
pemula. Salah satu alternatifnya adalah Turtle Programming berbasis Python. 
Pembelajaran Turtle versi desktop memiliki keterbatasan, seperti harus membaca 
buku panduan lalu mencoba kodenya di IDLE atau VS Code yang sudah diinstal, 
menyimpan file .py, dan menjalankannya secara terpisah. Penelitian ini bertujuan 
mengembangkan lingkungan p embelajaran interaktif berbasis web untuk 
pemrograman Turtle dengan model tutorial serta menganalisis kevalidannya. 
Lingkungan ini mengintegrasikan materi dan editor Turtle dalam satu platform. 
Penelitian menggunakan metode R&D dengan model ADDIE (analisis , desain, 
pengembangan, evaluasi). Produk dikembangkan menggunakan React, Node.js, 
Bootstrap, Skulpt, CodeMirror, dan Firebase. Pengumpulan data dilakukan melalui 
angket validasi oleh dua ahli materi dan dua ahli media menggunakan instrumen 
sesuai standar BSNP dan LORI. Uji fungsionalitas dilakukan dengan metode Black 
Box Testing oleh lima pengguna untuk menilai kesesuaian fungsi sistem dengan 
spesifikasi. Analisis data dilakukan secara kuantitatif melalui penilaian validitas 
dan fungsionalitas. Hasil menunjukkan validitas materi 82%, media 80%, dan 
fungsionalitas 100%. Lingkungan  ini dinyatakan valid dan berfungsi sepenuhnya 
untuk digunakan dalam proses pembelajaran pemrograman. 
Kata kunci: Turtle Programming, lingkungan pembelajaran, web interaktif, model 
tutorial, ADDIE

DEVELOPMENT OF AN INTERACTIVE WEB -BASED LEARNING 
ENVIRONMENT FOR TURTLE PROGRAMMING USING A TUTORIAL 
MODEL (Oleh: Khoyrur Roykhan; Pembimbing: Harja Santana Purba, Rizky 
Pamuji; 2025; 98 pages) 
 
ABSTRACT 
 
In the Grade VII Informatics subject of the Merdeka Curriculum, algorithms and 
programming are introduced using Scratch. To help students transition to textual 
programming, a beginner-friendly approach is required. One alternative is Python-
based Turtle Programming. However, the desktop version has limitations, such as 
requiring students to read manuals and try code using pre-installed tools like IDLE 
or VS Code, save .py files, and run them separately. This study aims to develop a 
web-based interactive lea rning environment for Turtle Programming using a 
tutorial model and analyze its validity. The platform integrates learning materials 
and a built -in Turtle editor. The research uses the R&D method with the ADDIE 
model (analysis, design, development, evaluat ion). The product was developed 
using React, Node.js, Bootstrap, Skulpt, CodeMirror, and Firebase. Data were 
collected through expert validation questionnaires based on BSNP and LORI 
standards. Functionality was tested using the Black Box method by five us ers to 
ensure system performance matched specifications. Data analysis was conducted 
quantitatively through assessments of content validity and system functionality. 
Results showed 82% content validity, 80% media validity, and 100% functionality. 
The learn ing environment was found to be valid and fully functional for use in 
programming education. 
Keywords: Turtle Programming, learning environment, interactive web, tutorial 
model, ADDIE

BAB I  
PENDAHULUAN 
 
 
1.1 Latar Belakang 
Kemampuan berpikir komputasional menjadi salah satu keterampilan 
penting di era digital saat ini. Salah satu cara efektif untuk melatih kemampuan 
tersebut adalah melalui pembelajaran pemrograman  (Maulana & Waluya, 2024) . 
Penelitian menunjukkan bahwa anak -anak yang dikenalkan pada pemrograman 
lebih awal memiliki potensi yang lebih tinggi dalam berpikir logis, pemecahan 
masalah, dan kreativitas (Silva et al., 2023). 
Pada mata pelajaran Informatika Kelas VII Kurikulum Merdeka, 
pembelajaran algoritma dan pemrograman pada Bab 7 diperkenalkan menggunakan 
Scratch, yaitu salah satu bentuk pemrograman visual berbasis blok . Pemrograman 
visual seperti ini membantu pemula memahami alur logika program dengan cara 
yang mudah dipahami dan sekaligus melatih kemampuan berpikir komputasional 
sejak dini (Azaharani et al., 2024). Namun, agar siswa dapat berkembang ke tahap 
berikutnya seperti menulis perintah sendiri dan memahami cara kerja program 
secara langsung, mereka perlu diperkenalkan dengan pemrograman tekstual guna 
mengasah kemampuan berpikir komputasional yang lebih mendalam. 
Salah satu pendekatan pemrograman tekstual yang ramah untuk pemula 
adalah Turtle Programming berbasis Python. Turtle Programming sendiri berasal 
dari bahasa Logo dan telah terbukti efektif dalam memperkenalkan konsep 
--- PAGE 17 ---
2 
 
 
 
pemrograman dasar secara visual, eksploratif, dan kreatif, karena menggunakan 
objek berbentuk kura-kura yang dapat digerakkan dengan perintah (Solomon et al., 
2020). Namun, dalam praktiknya, pembelajaran pemrograman Turtle dengan 
Python versi desktop memiliki beberapa keterbatasan. Siswa perlu menggunakan 
perangkat lunak seperti IDLE atau VS Code, lalu menulis kode dalam file .py, 
menyimpannya, menjalankan file tersebut, dan melihat hasilnya di jendela terpisah. 
Proses ini tidak terintegrasi dan sering kali membingungkan bagi pemula. Hal itu 
juga dapat  menyebabkan kehilangan konteks saat harus berpindah -pindah antara 
membaca materi, menulis kode, dan melihat hasil eks ekusi. Selain itu, menurut 
penelitian yang dilakukan (Bakar et al., 2020) , pemula yang baru belajar 
pemrograman mengalami kesulitan dalam penulisan sintaks. 
Berdasarkan uraian ini, peneliti melihat adanya kebutuhan untuk  
mengembangkan lingkungan pembelajaran yang menyatukan semua komponen 
pembelajaran pemrograman Turtle dalam satu platform berbasis web. Dalam satu 
tampilan, siswa dapat mengakses materi, menulis kode, menjalankan perintah, dan 
langsung melihat hasil visualnya melalui kanvas. Denga n pendekatan ini, proses 
belajar menjadi lebih terpadu, efisien, dan ramah bagi pemula. Dalam 
pengembangan environment ini, penulisan perintah Turtle dimodifikasi agar lebih 
menyerupai gaya bahasa Logo yang lebih sed erhana, seperti forward 100 alih-alih 
forward(100). Modifikasi ini bertujuan untuk membantu peserta didik lebih fokus 
memahami logika perintah, tanpa terbebani oleh aturan sintaks Python yang 
kompleks. Selanjutnya, lingkungan pembelajaran  ini dikembangkan dengan 
menggunakan model tutorial, yang memungkinkan siswa belajar secara bertahap:

3 
 
 
 
mulai dari memahami konsep, mencoba contoh kode, hingga menyelesaikan 
tantangan yang dirancang untuk memperkuat pemahaman. Model ini telah banyak 
digunakan dalam pengembangan media pembelajaran dan terbukti mendukung 
pemahaman progresif serta keterlibatan aktif siswa dalam proses belajar. 
Dengan demikian, pengembangan lingkugan pembelajaran interaktif berbasis 
web untuk pemrograman Turtle dengan model tutorial diharapkan dapat menjadi 
solusi alternatif dalam memperkenalkan pemrograman tekstual secara lebih 
sederhana, menyenangkan, dan mudah dipahami oleh peserta didik pemula.

BAB II  
TINJAUAN PUSTAKA 
 
 
2.1 Lingkungan Pembelajaran 
Lingkungan pembelajaran adalah konteks  di mana proses pendidikan 
berlangsung, mencakup semua elemen yang mempengaruhi pengalaman belajar 
siswa. Menurut (El-Sabagh, 2021) , lingkungan pendidikan yang baik dapat 
mendukung pengembangan keterampilan dan pengetahuan siswa, serta 
meningkatkan motivasi dan keterlibatan mereka dalam proses belajar. Lingkungan 
ini harus mampu menyesuaikan dengan kebutuhan dan gaya belajar siswa, sehingga 
setiap individu dapat belajar dengan cara yang paling efektif bagi mereka.  Dalam 
konteks pemrograman, lingkungan pembelajaran menyediakan berbagai sumber 
daya yang diperlukan untuk mendukung proses belajar. Ini termasuk materi 
pembelajaran, soal lat ihan, dan kesempatan untuk menjalankan kode secara 
langsung. Dengan adanya fitur ini, siswa dapat memahami konsep pemrograman 
dengan lebih baik, karena mereka tidak hanya belajar teori, tetapi juga dapat 
menerapkannya secara praktis. 
2.2 Lingkungan Pembelajaran Interaktif Berbasis Web 
Lingkungan pembelajaran interaktif berbasis web adalah platform yang 
memungkinkan siswa untuk aktif belajar menggunakan teknologi digital.  Menurut  
(Ouh et al., 2022) , lingkungan pembelajaran ini dirancang untuk meningkatkan 
keterlibatan siswa dalam pembelajaran, terutama dalam pemrograman. Dengan 
--- PAGE 21 ---

2.3.1 HTML 
Hypertext Markup Language  (HTML) adalah bahasa standar yang 
digunakan untuk menampilkan konten pada halaman website (Mariko, 2019), yang 
pertama kali dikembangkan oleh Tim Berners -Lee pada tahun 1991. HTML 
--- PAGE 22 ---

berfungsi untuk mengatur dan mendesain tampilan isi halaman, membuat tabel, 
serta mempublikasikan halaman secara online. Struktur dasar dari dokumen HTML 
terdiri dari elemen -elemen seperti  <html>, <head>, dan  <body>, di mana 
elemen <head> digunakan untuk m enempatkan identitas file, sedangkan

Seiring dengan perkembangan teknologi informasi dan komunikasi, HTML terus 
mengalami pembaruan untuk memenuhi kebutuhan pengguna dalam membuat

berperan penting dalam pengembangan aplikasi pembelajaran berbasis web, yang

2.3.2 CSS 
Cascading Style Sheets  (CSS) adalah teknologi yang digunakan untuk 
mempercantik tampilan HTML dan menentukan bagaimana elemen HTML 
ditampilkan di dalam browser  (Muthohir, 2021). CSS digunakan untuk mengatur 
berbagai aspek tampilan seperti warna, ukuran teks, jenis font, tata letak, jarak antar 
elemen, hingga animasi. CSS bekerja dengan cara memilih elemen HTML tertentu, 
lalu menerapkan aturan-aturan gaya padanya. 
Ada tiga cara utama dalam menerapkan CSS: 
(1) Inline CSS, ditulis langsung di dalam tag HTML menggunakan atribut style. 
(2) Internal CSS, ditulis dalam tag <style> di bagian <head> dokumen HTML. 
(3) Eksternal CSS, ditulis di file terpisah dengan ekstensi .css, lalu dihubungkan 
ke dokumen HTML menggunakan tag <link>.

2.3.5 Node.js 
Node.js adalah platform yang dibangun di atas mesin JavaScript V8

Dengan demikian, Node.js merupakan pilihan yang tepat untuk 
pengembangan aplikasi web yang membutuhkan kinerja tinggi, skalabilitas, dan 
kemampuan menangani permintaan secara bersamaan.

2.3.6 Bootstrap 
Bootstrap adalah kerangka kerja ( framework) front-end yang digunakan

 Bootstrap menyediakan pengaturan CSS global yang dapat digunakan 
untuk menata elemen dasar HTML, seperti typography, spacing, dan color. Selain 
itu, Bootstrap juga menyediakan sistem grid yang responsif, yang memungkinkan 
tata letak web menyesuaikan ukuran layar yang berbeda.

2.6 Black Box Testing 
Black Box Testing  adalah metode pengujian perangkat lunak yang 
digunakan untuk mengecek apakah sistem bekerja sesuai dengan fungsinya, tanpa 
melihat atau memeriksa isi kode program. Pengujian ini dilakukan dari sudut 
pandang pengguna, sehingga penguji cukup fokus pada inpu t dan output yang 
dihasilkan sistem. Metode ini cocok digunakan oleh pemula karena tidak 
memerlukan pemahaman bahasa pemrograman. Terdapat beberapa teknik dalam 
Black Box Testing, salah satunya adalah Equivalence Partitioning, yaitu teknik yang 
membagi input menjadi beberapa kelompok untuk diuji. Teknik ini bertujuan 
menemukan kesalahan pada fungsi, antarmuka, struktur data, performa, hingga 
inisialisasi sistem. Pengujian dengan metode ini dapat membantu memastikan 
bahwa sistem berjalan dengan benar sesuai desain awal (Uminingsih et al., 2022). 
2.7 Kriteria Validitas Produk 
Validitas adalah ukuran yang digunakan untuk menilai seberapa baik suatu 
alat atau media dalam melaksanakan fungsinya. Dalam konteks pengembangan 
media pembelajaran multimedia, validitas didefinisikan sebagai kemampuan media 
untuk mencapai tujuan yang tela h ditetapkan. Validitas tidak hanya berfokus pada 
--- PAGE 34 ---
19 
 
 
akurasi media dalam menyampaikan informasi, tetapi juga pada seberapa baik 
media tersebut dapat digunakan dan diterima oleh pengguna.  Dalam penelitian ini 
akan dilakukan uji validitas materi kepada ahli materi dan uji validitas media 
kepada ahli media. 
Dalam penilaian validitas materi berdasarkan Standar Nasional Pendidikan 
(BSNP), terdapat beberapa aspek penting yang digunakan untuk menilai kelayakan 
dan mutu materi. Aspek-aspek tersebut meliputi kelayakan isi, kelayakan Bahasa, 
dan kelayakan penyajian. Dalam validitas media pembelajaran digunakan indicator 
penilaian berdasarkan  Learning Object Review Instrument (LORI)  version 2.0 
tahun 2009, validitas media pembelajaran dinilai berdasarkan delapan aspek utama,  
yang digunakan, meliputi ,Feedback and Adaptation (Umpan Balik dan Adaptasi), 
Presentation Design  (Penyajian Tampilan) , Interaction Usability  (Interaksi 
Pengguna) dan Accessibility (Aksesibilitas). 
Validitas dihitung menggunakan rumus yang membandingkan skor yang 
diperoleh dari penilaian validator dengan skor maksimum yang mungkin. Hasil 
validitas kemudian diklasifikasikan berdasarkan kriteria tertentu untuk menentukan 
apakah media tersebut valid dan  layak digunakan. Dengan demikian, validitas 
menjadi indikator penting dalam menentukan kualitas dan efektivitas media 
pembelajaran (Hutabri, 2022).

3.1 Jenis Penelitian 
Jenis penelitian yang digunakan dalam penelitian ini adalah Research and 
Development (R&D). Research and Development  Penelitian dan Pengembangan 
adalah suatu metode penelitian yang bertujuan untuk menghasilkan produk atau 
model baru melalui proses ilmiah yang sistematis. Penelitian ini dimulai dari 
analisis kebutuhan untuk mengidentifikasi masalah yang perlu dipecahkan, 
kemudian dilanjutkan dengan pengembangan produk atau model, evaluasi, dan 
validasi (Okpatrioka, 2023; Waruwu, 2024) . R&D juga dapat digunakan untuk 
menyempurnakan produk yang sudah ada dengan memperbaiki kualitas atau 
menambahkan fitur baru. Dalam konteks pendidikan, R&D banyak digunakan 
untuk mengembangkan model pembelajaran, modul pelatihan, atau alat bantu 
pembelajaran yang efektif dan inovatif.  Salah satu pakar yang mengembangkan 
konsep metode penelitian dan pengembangan bernama Borg and Gall menjelaskan 
empat ciri utama metode penelitian pengembangan ini (Okpatrioka, 2023), yaitu: 
Pertama, adanya penyelidikan terhadap hasil penelitian berkaitan dengan 
produk yang akan dikembangkan. Peneliti melakukan kajian atau penelitian 
pendahuluan (preliminary) untuk mengembangkan hasil penelitian yang berkaitan 
dengan produk yang akan dikembangkan. Kedua, pengembangan produk 
berdasarkan temuan analisis masalah. Pengembangan produk berdasarkan hasil 
--- PAGE 41 ---
26 
 
 
penelitian awal (pendahuluan). Ketiga, pengujian lapangan di lingkungan yang 
pada akhirnya akan digunakan. Pengujian lapangan dilakukan di lingkungan atau 
situasi yang paling realistis di mana produk akan digunakan. Keempat, ditinjau 
untuk mengatasi semua kekurangan yang diidentifikasi selama fase pengujian 
lapangan. Peneliti melakukan revisi untuk memperbaiki kelemahan yang 
ditemukan pada tahap uji lapangan. Dari empat ciri utama tersebut dapat 
disimpulkan bahwa ciri peneli tian pengembangan diawali dengan proses analisis 
terhadap produk terdahulu, pengembangan produk, uji lapangan, dan revisi. 
Keempat hal tersebut merupakan tahapan yang perlu dilakukan pada penelitian 
pengembangan. 
3.2 Model Pengembangan 
Produk yang dikembangkan merupakan sebuah media pembelajaran 
interaktif berbasis web yang berisi topik Pemrograman Turtle dengan menggunakan 
model tutorial. Produk ini dirancang menggunakan model pengembangan ADDIE 
(Analyze, Design, Develop, Implement, Evaluate), yang merupakan kerangka kerja 
sistematis untuk merancang dan mengembangkan materi pembelajaran yang 
efektif. Proses ini dimulai dengan fase analisis, di mana kebutuhan dan masalah 
yang ada diidentifikasi untuk memastikan bahwa pengembangan yang dilakuka n 
relevan dan sesuai dengan konteks yang dihadapi (Branch, 2009). Selanjutnya, pada 
fase desain, tujuan pembelajaran ditentukan dan strategi pengajaran dirancang 
untuk mencapai hasil yang diinginkan. Fase pengembangan melibatkan pembuatan 
dan validasi sumber belajar yang akan digunakan dalam proses pembelajaran. 
Implementasi dilakukan dengan mempersiapkan lingkungan belajar dan melibatkan 
--- PAGE 42 ---

siswa dalam pengalaman belajar yang telah dirancang. Terakhir, evaluasi dilakukan 
untuk menilai kualitas produk pembelajaran dan proses yang telah dilaksanakan, 
serta untuk melakukan perbaikan yang diperlukan (Branch, 2009).  
Model ADDIE dapat digunakan untuk pengembangan materi dan media 
pembelajaran. Dalam penelitian yang dilakukan oleh (Andi Rustandi & Rismayanti, 
2021), mereka menunjukkan bahwa penerapan model ADDIE dalam

media yang dinyatakan "sangat layak" . Selain itu,  (Mulyasari et al., 2023)  
menekankan bahwa model ADDIE dapat digunakan untuk mengembangkan bahan 
ajar yang efektif di sekolah dasar, dengan hasil validasi yang menunjukkan bahwa 
bahan ajar yang dikembangkan sangat baik dan dapat digunakan secara efektif 
dalam proses pembelajaran.  Dengan demikian, penerapan model ADDIE dalam 
pengembangan materi dan media pembelajaran dapat memberikan dampak positif 
terhadap kualitas pendidikan dan hasil belajar siswa.

3.3.1 Tahap Analisis (Analyze) 
Tahap Analisis merupakan langkah awal dalam model pengembangan 
pembelajaran ADDIE yang bertujuan untuk mengidentifikasi penyebab utama dari 
kesenjangan kinerja (performance gap) antara kondisi saat ini dengan kondisi yang 
diharapkan dengan studi literatur terhadap buku, artikel, dan aplikasi relevan. 
Dalam tahap ini, dilakukan validasi terhadap adanya kesenjangan kinerja serta 
penetapan tujuan pembelajaran yang ingin dicapai. Selanjutnya, ditentukan siapa 
audiens yang menjadi sasaran program pembelajaran, serta diidentifikasi sumber 
daya yang diperlukan untuk mendukung proses pembelajaran. Selain itu, tahap ini 
juga mencakup penentuan sistem penyampaian pembelajaran.  Pada tahap ini pula 
dilakukan Analisis Konten terhadap materi yang akan disampaikan, Analisis Model 
Tutorial untuk menentukan pendekatan pedagogi yang digu nakan, serta Analisis 
Teknologi yang berkaitan dengan pengembangan environment pembelajaran yang 
sesuai.

c. Analisis penerapan model tutorial pada media 
Model tutorial merupakan salah satu pendekatan dalam pembelajaran 
berbasis komputer yang menempatkan sistem sebagai tutor atau pembimbing dalam 
proses belajar peserta didik. Dalam konteks pengembangan media pembelajaran 
interaktif berbasis web untuk materi pemrograman turtle, model tutorial diterapkan 
untuk membimbing peserta didik secara bertahap dari tahap memahami konsep 
dasar hingga menyelesaikan tantangan pemrograman. 
Menurut Rusman (2012), terdapat delapan langkah utama dalam 
penerapan m odel tutorial berbasis komputer. Ke delapan langkah tersebut 
diintegrasikan ke dalam media pembelajaran sebagai berikut: 
1) Pendahuluan (introduction) 
Pada bagian pendahuluan, peserta didik akan disambut dengan halaman 
pengenalan ( landing page ) yang menjelaskan secara ringkas tujuan dari media 
pembelajaran ini. Halaman ini juga mengarahkan peserta didik untuk mulai dari 
materi awal yang memperkenalkan konsep Turtle secara sederhana dan visual. 
2) Penyajian Informasi (Presentation of Information) 
Materi disajikan dalam bentuk teks penjelas, ilustrasi visual, serta 
potongan kode. Penyampaian materi dilakukan secara bertahap dan terstruktur agar 
peserta didik dapat memahami konsep -konsep dasar pemrograman secara 
sistematis. Informasi disajikan pada d iawal pembelajaran sebelum peserta didik 
mencoba praktikum atau menjawab soal. 
3) Pertanyaan dan Respon (Question of Responses) 
--- PAGE 62 ---
47 
 
 
Setelah memahami materi, peserta didik diberikan pertanyaan atau latihan 
yang harus diselesaikan. Bentuk latihan ini dapat berupa pertanyaan pilihan ganda, 
isian singkat, atau instruksi untuk menjalankan kode tertentu di editor. Latihan 
disusun untuk memperkuat pemahaman serta mendorong keterlibatan aktif peserta 
didik dalam proses belajar. 
4) Penilaian Respon (Judging of Responses) 
Media pembelajaran dilengkapi dengan sistem evaluasi otomatis yang 
akan memeriksa jawaban peserta didik, baik berupa kuis maupun hasil eksekusi 
kode. Sistem ini akan mengevaluasi apakah jawaban yang diberikan sesuai dengan 
kriteria yang ditentukan, seperti output gambar yang dihasilkan dari instruksi turtle. 
5) Pemberian Respon Balik (Providing Feedback about Responses) 
Setelah sistem melakukan penilaian, peserta didik akan menerima umpan 
balik secara langsung. Jika jawaban benar, maka peserta didik akan diberi 
konfirmasi positif dan bisa melanjutkan ke materi berikutnya. Jika jawaban salah, 
akan diberikan penjelasan atau petunjuk untuk memperbaiki kesalahan. 
6) Pengulangan (Remedial) 
Bagi peserta didik yang belum mencapai hasil yang diharapkan, sistem 
akan memberikan kesempatan untuk mengulang materi atau mencoba kembali 
latihan yang belum berhasil. Proses ini memungkinkan peserta didik belajar dalam 
kecepatan masing-masing hingga mereka benar-benar memahami materi. 
7) Segmen Pengaturan Pembelajaran (Sequencing Lesson Segment) 
Pembelajaran dibagi ke dalam segmen-segmen yang terstruktur, mulai dari 
pengenalan konsep dasar hingga ke aplikasi dan tantangan yang lebih kompleks. 
--- PAGE 63 ---
48 
 
 
Pengaturan ini dibuat secara berurutan dan sistematis, mengikuti alur logika dari 
mudah ke sulit, untuk memastikan pembelajaran berlangsung secara progresif dan 
mendalam. 
8) Penutup (closing) 
Setelah menyelesaikan seluruh materi dan kuis, peserta didik akan 
diarahkan ke halaman penutup yang memberikan apresiasi atas keberhasilan 
mereka menyelesaikan pembelajaran.

Berdasarkan hasil analisis umum, analisis konten dan analisis penerapan

Dalam mengembangkan sebuah aplikasi web, penggunaan teknologi dasar 
seperti HTML, CSS, dan JavaScript menjadi fondasi utama. Namun, untuk 
membangun aplikasi web yang kompleks dan interaktif, diperlukan pula integrasi 
dengan teknologi modern seperti framewo rk dan pustaka pendukung.  Pada 
penelitian ini, pengembangan media pembelajaran interaktif dilakukan dengan 
menggunakan React.js sebagai pustaka utama untuk membangun antarmuka 
pengguna (UI). React memberikan kemudahan dalam membuat komponen UI yang 
modular, dinamis, dan dapat digunakan kembali, sehingga sangat mendukung 
proses pengembangan aplikasi yang terstruktur dan efisien.  Untuk sisi backend, 
digunakan Node.js sebagai platform server-side yang berbasis JavaScript. Node.js 
dikombinasikan dengan framework Express.js untuk membangun server API yang 
menangani otentikasi pengguna, penyimpanan data, dan pengelolaan progres 
belajar. Kombinasi ini memungkinkan komunikasi client-server yang cepat dan 
efisien menggunakan bahasa pemrograman yang sama, yaitu JavaScript. 
Agar tampilan aplikasi lebih menarik, responsif, dan mudah digunakan, 
digunakan pustaka Bootstrap yang diintegrasikan ke dalam komponen React.

pembelajaran ini dikembangkan dengan menggunakan model pengembangan 
ADDIE yang sudah dibatasi.  Media ini juga telah dilakukan pengujian 
fungsionalitas menggunakan m etode Black Box Testing  yang menunjukan 
bahwa berjalan dengan baik dan sesuai dengan fungsinya. 
(2) Setelah selesai dikembangkan dilakukan uji validitas pada materi dan media. 
Uji validitas tersebut dilakukan oleh ahli materi dan ahli media. Hasil validasi 
menunjukkan bahwa media ini memperoleh persentase capaian 82% untuk 
materi yang termasuk dalam kategori “Sangat Tinggi” dan 80% untuk media 
yang termasuk dalam kategori "Tinggi". Hal ini menunjukkan bahwa

5.2 Saran 
Peneliti sangat menyadari bahwa penelitian ini masih banyak terdapat 
kekurangan baik disengaja maupun tidak disengaja. Adapun saran sangat 
diperlukan dalam penelitian ini dapat dijadikan acuan untuk peneliti selanjutnya, 
agar dapat melakukan penelitian dan  pengembangan dengan maksimal. Adapun 
saran-saran yang diberikan adalah sebagai berikut:  
(1) Aplikasi yang telah di kembangkan dapat dikembangkan lebih lanjut dengan 
menambahkan fitur sistem penghargaan seperti badge, poin, atau level untuk 
memberikan motivasi tambahan kepada siswa dalam menyelesaikan materi, 
latihan, dan tantangan. 
(2) Tampilan media perlu dioptimalkan untuk mendukung berbagai jenis 
perangkat, terutama mobile, agar siswa dapat mengakses materi kapan saja dan 
di mana saja. Selain itu, aspek aksesibilitas untuk pengguna berkebutuhan 
khusus, seperti pilihan kontras warna tinggi atau pembaca layar, juga sebaiknya 
mulai dipertimbangkan dalam pengembangan selanjutnya. 
(3) Agar efektivitas aplikasi dapat dievaluasi lebih komprehensif, uji coba 
lapangan sebaiknya dilakukan. Penelitian lanjutan juga dapat menggali lebih 
dalam dampak penggunaan media ini.
