# Laboratorium Logika Code Maze

Alur belajar: prediksi posisi dan arah → telusuri tiap instruksi → bandingkan hasil → refleksi dan perbaikan kode.

1. Tulis kode, lalu isi prediksi X, Y dan arah akhir. Posisi relatif terhadap titik awal (0, 0); X positif ke timur, Y positif ke selatan. Satu satuan adalah satu kotak.
2. Klik **Kunci prediksi & telusuri**. Editor dan prediksi dikunci selama penelusuran.
3. Gunakan **Instruksi berikutnya** atau **Sebelumnya**. Posisi, arah, checkpoint, baris kode, dan karakter mengikuti instruksi yang sedang ditinjau. Tabrakan menghentikan penelusuran di lokasi sebenarnya, yang bisa berada di antara kotak.
4. Setelah instruksi terakhir, bandingkan prediksi dengan hasil. Isi catatan refleksi, lalu pilih **Kembali ke editor**. Catatan bersifat sementara dan dihapus saat memulai prediksi baru atau meninggalkan halaman.
5. Perbaiki kode, ulangi prediksi, atau pilih **Run Code** untuk penilaian server.

Penelusuran tidak memberikan XP, menyimpan checkpoint penilaian, atau membuka chapter. Sebelum menampilkan hasil, server mencatat penggunaan bantuan melalui aturan Hint yang sama: penalti 5 poin sekali, tidak berlipat jika menggunakan Hint dan penelusuran bersama. Koneksi diperlukan saat memulai agar bantuan tercatat. Pada chapter 3, mulai **Ulangi penilaian** untuk mencoba penyelesaian bersih dan badge. Kesalahan prediksi tidak menambah penalti tersendiri.

Simulator yang dipakai sama dengan Run Code; semua sintaks divalidasi sebelum penelusuran. Nomor baris asli dipertahankan, termasuk baris komentar/kosong. Reward tetap dihitung oleh server saat kode dikirim lewat Run Code.

Fitur ini adalah kontribusi pendekatan belajar proyek; keberadaannya tidak menggantikan kewajiban atribusi materi, kode, atau aset dari sumber lain.
